# PrintEasy — Sistema de Preparação de Imagens para Impressão

Projeto Integrador de Análise e Projeto de Sistemas, 2026.

**Instituição:** IFPR — Centro de Referência Ponta Grossa  
**Curso:** Técnico em Informática Integrado ao Ensino Médio  
**Autoria:** João Vitor  
**Cliente:** Responsável por um serviço de impressão.

## Apresentação do projeto

O PrintEasy é um sistema para facilitar a preparação de imagens para impressão em dispositivos Android. Atualmente, a responsável precisa posicionar, centralizar e redimensionar manualmente as imagens recebidas pelo WhatsApp, utilizando o aplicativo da Epson.

O sistema permitirá selecionar e organizar várias fotos automaticamente, configurar tamanhos de papel e de imagens, realizar ajustes manuais, visualizar a montagem e gerar arquivos PDF para impressão. Também permitirá salvar preferências e modelos de organização.

Seu objetivo é reduzir o tempo gasto na preparação das imagens e facilitar o atendimento aos clientes.
