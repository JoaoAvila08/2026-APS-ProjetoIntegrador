## Apresentação do projeto

O PrintEasy é um sistema de preparação de imagens para impressão, desenvolvido para facilitar o trabalho de sua cliente. Atualmente, ela precisa posicionar e redimensionar manualmente as imagens recebidas pelo WhatsApp, utilizando o aplicativo da Epson. O sistema permitirá centralizar e organizar automaticamente as fotos, escolher o tamanho do papel e visualizar o resultado antes da impressão. Seu objetivo é reduzir o tempo gasto nessa preparação.
