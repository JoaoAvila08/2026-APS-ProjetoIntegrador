# 4.1 Descrição do Projeto

## O problema, na voz do cliente

> "O que mais me tira a paciência no dia a dia é o tempo que eu perco tendo que arrastar e alinhar foto por foto no aplicativo da Epson. Quando o cliente manda várias imagens pelo WhatsApp, preciso abrir uma por uma, ajustar o posicionamento e redimensionar tudo manualmente para evitar cortes na impressão. Se houvesse um jeito de selecionar as fotos e deixar tudo centralizado e organizado automaticamente na folha, eu conseguiria atender muito mais rápido!"
>
> (Responsável pelo serviço de impressão)

## Propósito

Atualmente, a preparação das imagens para impressão é realizada manualmente pelo aplicativo da Epson em um celular Android. A responsável precisa posicionar, centralizar e redimensionar cada foto, além de organizar várias imagens quando são impressas na mesma folha. Esse processo demanda tempo e trabalho repetitivo.

O PrintEasy será desenvolvido para automatizar e facilitar a preparação das imagens, permitindo organizar fotos em folhas de diferentes tamanhos, realizar ajustes e gerar arquivos prontos para impressão.

## Objetivo

Reduzir o tempo gasto na preparação de imagens para impressão, permitindo selecionar várias fotos, configurar o papel e as medidas desejadas, organizar as imagens automaticamente, realizar ajustes manuais e gerar um arquivo PDF para impressão.

## Quem usa

- **Responsável pela impressão:** utiliza o sistema para selecionar e organizar imagens, configurar as folhas, ajustar as fotos, visualizar a montagem e gerar os arquivos PDF.
- **Clientes:** não utilizam o sistema. Apenas enviam as imagens pelo WhatsApp para a responsável pela impressão.

## Escopo

- O sistema permite selecionar, remover, duplicar, girar e definir a quantidade de cópias das imagens.
- O sistema permite escolher tamanhos de papel predefinidos ou personalizados, além da orientação vertical ou horizontal.
- O sistema permite definir medidas personalizadas para as fotos.
- O sistema organiza e centraliza automaticamente as imagens, aproveitando o espaço disponível e evitando cortes.
- O sistema permite ajustar manualmente a posição, o tamanho e a ordem das imagens, além de desfazer alterações.
- O sistema permite configurar margens, visualizar a montagem e receber avisos quando não houver espaço suficiente na folha.
- O sistema permite gerar arquivos PDF, salvá-los no celular e compartilhá-los pelo WhatsApp.
- O sistema permite salvar preferências e modelos de organização para reutilização em trabalhos futuros.

## Fora do escopo

- O sistema não realizará pagamentos, pois o controle financeiro não faz parte do problema identificado.
- O sistema não gerenciará pedidos ou entregas, pois seu foco é a preparação das imagens para impressão.
- O sistema não realizará o controle de clientes ou conversas do WhatsApp.
- O sistema não dependerá de integração direta com impressoras Epson; os arquivos PDF gerados poderão ser abertos em aplicativos compatíveis para impressão.

## Características principais

O sistema será desenvolvido para dispositivos móveis Android, com interface em português e comandos simples e intuitivos. Deverá preservar a qualidade das imagens durante a geração dos arquivos PDF e permitir que a responsável personalize as configurações de acordo com cada trabalho.

As preferências e os modelos de organização poderão ser salvos para facilitar utilizações futuras. A pré-visualização deverá apresentar a disposição das imagens antes da geração do arquivo final.
