# 3.1 Abordagem de Desenvolvimento

O projeto seguirá a abordagem iterativa e incremental, desenvolvendo o sistema por etapas. Cada etapa será dedicada à construção de uma seção da documentação, seguindo a ordem proposta nas aulas.

Ao final de cada ciclo, uma parte do projeto será produzida, revisada e adicionada ao repositório no GitHub. As novas seções serão conferidas com as anteriores para evitar contradições. Sempre que possível, as etapas serão apresentadas à cliente para verificar se atendem às suas necessidades.

Essa abordagem foi escolhida em vez do modelo cascata porque permite identificar e corrigir problemas durante o desenvolvimento, sem esperar até o final. Como o projeto será individual, não serão utilizadas cerimônias do Scrum que dependem de uma equipe, como reuniões diárias e divisão de tarefas, mas serão aproveitados ciclos curtos de desenvolvimento e revisão.
