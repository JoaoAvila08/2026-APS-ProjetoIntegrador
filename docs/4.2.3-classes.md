# 4.2.3 – Modelagem de Classes

## 1. Identificação dos substantivos

A partir dos requisitos funcionais e dos casos de uso do PrintEasy, foram identificados os seguintes candidatos a classes:

| Substantivo | Candidato a classe? | Justificativa |
|---|---|---|
| Imagem | Sim | Representa os arquivos de imagem utilizados na impressão. |
| Folha | Sim | Armazena as configurações do papel utilizado. |
| Montagem | Sim | Representa a organização das imagens para impressão. |
| ItemMontagem | Sim | Representa cada imagem posicionada em uma folha. |
| Modelo | Sim | Armazena configurações que podem ser reutilizadas. |
| PDF | Não | É o arquivo produzido pelo sistema, não uma entidade principal. |
| Impressora | Não | A impressão é realizada por aplicativo externo. |

## 2. Definição das classes

Foram definidas cinco classes principais:

- **Montagem:** controla a organização das páginas e a geração do PDF.
- **Folha:** representa o papel e suas configurações.
- **ItemMontagem:** armazena a posição, as dimensões e a quantidade de cópias de uma imagem.
- **Imagem:** representa os arquivos selecionados pelo usuário.
- **Modelo:** armazena configurações reutilizáveis.

Os atributos e operações de cada classe estão apresentados no diagrama de classes.

## 4. Teste com objetos

Foram definidos quatro objetos de exemplo para verificar os atributos e as relações entre as classes.

| Objeto | Classe | Valores dos atributos |
|---|---|---|
| montagem1 | Montagem | quantidadePaginas = 1 |
| folha1 | Folha | tipoPapel = A4, largura = 21, altura = 29.7, orientacao = Retrato, margens = 0.5 |
| imagem1 | Imagem | nomeArquivo = foto.jpg, formato = JPG |
| item1 | ItemMontagem | quantidadeCopias = 2, posicaoX = 1, posicaoY = 1, largura = 5, altura = 7, ordem = 1 |

Os objetos demonstram como uma montagem pode possuir folhas, que contêm itens associados às imagens utilizadas.

As multiplicidades definidas no diagrama permitem uma ou mais folhas por montagem, nenhum ou vários itens por folha e uma imagem associada a cada item de montagem.

## 5. Rastreabilidade

A tabela relaciona os requisitos funcionais aos casos de uso e às classes responsáveis por suas funcionalidades.

| Requisito | Caso de uso | Classes relacionadas | Operações principais |
|---|---|---|---|
| RF01 – Gerenciar imagens | Gerenciar imagens | Imagem, ItemMontagem | selecionar(), remover(), duplicar(), girar() |
| RF02 – Configurar folha | Configurar folha | Folha | configurar() |
| RF03 – Definir medidas das fotos | Configurar folha | Folha, ItemMontagem | configurar(), redimensionar() |
| RF04 – Organizar imagens | Organizar imagens | Montagem, ItemMontagem | organizarAutomaticamente() |
| RF05 – Ajustar montagem | Ajustar montagem | ItemMontagem | mover(), redimensionar(), reordenar() |
| RF06 – Pré-visualizar montagem | Gerar PDF | Montagem | previsualizar() |

Dessa forma, os requisitos funcionais estão relacionados aos casos de uso e às classes responsáveis por implementar suas funcionalidades.
